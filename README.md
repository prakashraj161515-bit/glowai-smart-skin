# GlowAI – Skin & Face Coach 🧴✨

AI-powered personalized skin and face coaching app. Built with Next.js, Tailwind CSS, and Framer Motion.

## 🚀 Deployment Instructions

### 1. Push to GitHub
If you haven't created a repository yet, create one at [github.com/new](https://github.com/new). Then run:

```bash
git remote add origin https://github.com/YOUR_USERNAME/glowai.git
git branch -M main
git push -u origin main
```

### 2. Deploy to Vercel
1. Go to [vercel.com/new](https://vercel.com/new).
2. Import your `glowai` repository.
3. Configure Environment Variables (if needed, though the API key is already obfuscated in code).
4. Click **Deploy**.

## 🛠️ Local Development

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run development server:
   ```bash
   npm run dev
   ```
